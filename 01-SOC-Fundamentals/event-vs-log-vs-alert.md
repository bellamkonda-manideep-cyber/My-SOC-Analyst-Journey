# 📊 Event vs Log vs Alert

Understanding these basics is essential for SOC work.

---

## 🔹 Event

An action that happens on a system.

Example:
User login, file access, process execution.

---

## 🔹 Log

A record of an event.

Example:
“User kali failed to authenticate at 14:20”

---

## 🔹 Alert

A notification generated when logs match suspicious patterns.

Alert is generated by tools based on rules.

---

## 🧠 SOC Flow

Event → Log → Alert → Analyst Investigation

---

## 🔑 Principle

> “Alerts come from logs, logs come from events.”
