# 🛡 My SOC Analyst Journey

This repository documents my structured learning path and hands-on simulations toward becoming a **job-ready SOC Analyst (L1)**.

The focus of this journey is practical SOC skills including alert analysis, incident handling, authentication monitoring, attack chain understanding, and detection engineering — not just tool usage.

---

## 🔧 Skills Demonstrated

- Alert triage and prioritization  
- Authentication log analysis  
- False positive vs True positive identification  
- Incident escalation (SOC L1 → SOC L2)  
- SOC analyst documentation and reporting  
- Attack chain analysis (Execution → Persistence → Lateral Movement → Impact)  
- Threat hunting fundamentals  
- Detection gap identification and visibility engineering  

---

## 🧪 Hands-on Lab Areas

- SSH brute-force detection  
- Web reconnaissance detection  
- Authentication attack pattern analysis  
- Suspicious command execution monitoring (Auditd + Wazuh)  
- Persistence detection via cron jobs  
- Outbound behavior hunting  
- Incident correlation and attack chain linking  

---

## 🧠 Analyst Mindset Developed

- Evidence-based decision making  
- Context over alert severity  
- Business impact–focused prioritization  
- Calm and structured incident handling  
- Pattern-based threat hunting  
- Clear documentation for escalation and audits
